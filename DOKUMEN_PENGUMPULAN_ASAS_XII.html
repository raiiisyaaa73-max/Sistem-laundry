BAGIAN 1: PENJELASAN DATABASE & MIGRATION

Aplikasi SIM Laundry menggunakan basis data MySQL bernama db_laundry yang terdiri atas 3 tabel utama yang saling terhubung menggunakan relasi Eloquent dan Foreign Key.

1. Tabel users

File Migration: database/migrations/0001_01_01_000000_create_users_table.php

Digunakan untuk menyimpan kredensial pengguna yang dapat login ke dalam sistem, dilengkapi dengan kolom pembeda hak akses:

  • id (BigInteger, Primary Key, Auto Increment)
  • name (String, Nama lengkap pengguna)
  • email (String, Unique, Alamat email login)
  • password (String, Hash Bcrypt sandi pengguna)
  • role (Enum: 'admin', 'kasir', default: 'kasir'): Membedakan hak akses halaman & fitur.
  • timestamps (created_at & updated_at)

2. Tabel layanans

File Migration: database/migrations/2026_11_24_052329_create_layanans_table.php

Menyimpan data paket jenis pencucian laundry yang ditawarkan kepada pelanggan:

  • id (BigInteger, Primary Key, Auto Increment)
  • nama_layanan (String, Nama jenis layanan, contoh: Reguler, Ekspres, Superkilat)
  • harga_per_kg (Integer, Biaya per kilogram dalam rupiah)
  • estimasi_waktu (String, Estimasi durasi pengerjaan, contoh: 3-4 hari, 5 jam)
  • timestamps

3. Tabel transaksis

File Migration: database/migrations/2026_11_24_052339_create_transaksis_table.php

Menyimpan seluruh data penerimaan pesanan cucian pelanggan yang berelasi dengan tabel layanans:

  • id (BigInteger, Primary Key, Auto Increment)
  • layanan_id (ForeignId): Terhubung ke layanans(id) dengan atribut onDelete('cascade') agar jika layanan dihapus, data transaksi terkait terjaga integritasnya.
  • nama_pelanggan (String, Nama konsumen pemilik cucian)
  • no_hp (String, Kontak WhatsApp/telepon pelanggan)
  • berat (Decimal 8,2, Berat timbangan cucian dalam kilogram)
  • total_harga (Integer, Total biaya yang dihitung: berat * harga_per_kg)
  • status (Enum: 'Proses', 'Selesai', default: 'Proses'): Status pengerjaan laundry.
  • timestamps

BAGIAN 3: CRUD DATA LAYANAN

Fitur CRUD Layanan memungkinkan Administrator mengelola daftar tarif dan paket laundry secara dinamis.

Data Layanan Wajib yang Disediakan:

  1. Reguler: Rp 7.000 / kg | Estimasi Waktu: 3-4 hari
  2. Ekspres: Rp 12.000 / kg | Estimasi Waktu: 1-2 hari
  3. Superkilat: Rp 25.000 / kg | Estimasi Waktu: 5 jam selesai

Fungsionalitas:

  • Create: Form modal untuk menambah paket layanan baru dengan validasi nama unik dan harga minimal.
  • Read: Tabel daftar layanan berformat mata uang Rupiah (contoh: Rp 7.000) dan jumlah transaksi yang menggunakan layanan tersebut.
  • Update: Halaman edit untuk memperbarui nama, tarif per kg, atau durasi estimasi pengerjaan.
  • Delete: Menghapus paket layanan dengan modal/dialog konfirmasi keamanan.

BAGIAN 4: ORDER & REKAP ORDER TRANSAKSI

1. Form Pencatatan Transaksi (Order Baru):

  • Input: Nama Pelanggan, Nomor HP/WhatsApp, Pilihan Jenis Layanan, dan Berat Timbangan Cucian (kg).
  • Logika Perhitungan Otomatis: Menggunakan rumus total_harga = berat * harga_per_kg. Total harga terkalkulasi secara langsung (*live preview*) di frontend saat kasir mengetik berat cucian dan divalidasi ulang di backend controller.

2. Tabel Rekap Transaksi Laundry:

  • Menampilkan nomor nota (contoh: #0001), tanggal penerimaan, nama pelanggan, kontak WhatsApp, paket layanan, berat, dan total tarif.
  • Badge Status Warna:
    • Status Proses: Kuning / Amber (Menandakan cucian sedang dicuci/disetrika).
    • Status Selesai: Hijau / Success (Menandakan cucian siap diambil pelanggan).
  • Aksi Cepat Status: Tombol 1-klik untuk langsung mengubah status pengerjaan dari Proses menjadi Selesai.
  • Filter & Pencarian: Menyaring data berdasarkan status pengerjaan, paket layanan, rentang tanggal, dan kata kunci nama/HP.
  • Fitur Cetak Nota & Laporan: Fitur print struk kasir (*thermal receipt*) dan cetak rekap laporan transaksi (dukungan fungsi window.print()).
